# CineVerse Movie Application

CineVerse is a modern movie application developed using HTML, CSS
and JavaScript.

## Features

- Movie search
- Genre filtering
- Movie details
- Movie ratings
- Wishlist
- Movie clips and teasers
- Notifications
- In Theaters
- Coming Soon
- Movie mini-games
- Responsive cinema-themed interface

## Technologies Used

- HTML
- CSS
- JavaScript
